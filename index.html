Reshardable Iterator · Deterministic Recovery

4 个模拟 worker 缩到 2 个：全局顺序与梯度更新逐步一致

检查点只保存已提交全局批次边界上的扁平样本游标和模型权重。 若崩溃时上一全局步只有部分 worker 完成，则丢弃尚未提交的半批梯度， 回到该批起点，并用新的 2-worker 分片重放完整全局批次。

所有训练计算都在本页 JavaScript 中完成；无后端、无随机网络请求。数据集、种子、学习率和初始权重固定。

1只检查点全局游标

不保存会随拓扑失效的各 rank 私有偏移。恢复时用同一个 epoch/seed 生成全局排列， 再按 worldSize=2 重新切分同一批样本。

2半批回滚并重放

优化器全局步是原子的。已完成 worker 的局部梯度若未进入提交，就不能形成权重检查点； 恢复到该全局批起点，整批在 2 个 worker 上重算。

3按全局顺序归约

worker 数改变分组方式，但梯度按 sequencePosition 规范排序后累加，因此本演示中连 IEEE-754 结果和最终权重都逐位相同。
